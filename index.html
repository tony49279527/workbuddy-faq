一、下载与安装

Q1Mac 和 Windows 电脑都能装客户端吗？

可以。Mac 和 Windows 都支持，下载安装方式一致，到官网下载对应版本安装即可。

官网：https://www.workbuddy.cn/

待补充：支持的 macOS / Windows 最低系统版本要求

Q2从哪里下载？

官网首页即可下载：https://www.workbuddy.cn/

待补充：下载入口截图 / 具体点击路径

二、注册与认证

Q3从官网自己注册，还是从我们这里注册？

看你的使用场景：

  • 只是个人使用：官网自己注册就行，怎么方便怎么来。
  • 要用企业版协同功能：需要在我们这里注册关联，才能开通多人协作、席位管理这些能力。
Q4我已经注册过一个账号了，还需要重新注册吗？

不需要。直接沿用已注册的账号即可。

重复注册容易把数据分散在多个账号里，后续合并很麻烦，建议一开始就固定一个账号用下去。
另外：如果想使用多账号协同，可以在我们这里注册关联，不用另起新账号。
Q5注册完成后第一步要做什么？

先完成账号实名认证。

未实名认证的账号在后续购买、企业协作等环节会受限，建议注册后第一时间完成。

建议直接认证企业账户，后续办理账号关联、开具发票等都会方便很多。

待补充：实名认证的具体操作路径 + 截图

三、账号与登录

Q6一个账号可以几个人同时登录吗？

个人版不支持多人共用。

个人版账号与一个微信或手机号绑定，登录身份是唯一的，无法用于企业协作。如果确实需要多人使用，请看 Q7。

Q7我想让团队一起用，怎么办？

升级企业版。企业版可以在企业账户内统一管理成员，并按需分配席位；人员变动时，席位可以在账户内重新分配，不需要重新购买。

买完之后怎么把席位分给同事，见 Q13。

四、个人版 / 企业版怎么选

Q8个人版和企业版主要区别是什么？

核心区别在协作能力：

个人版企业版
登录方式一个微信 / 手机号企业账户统一管理
多人协作不支持支持
席位管理无可在账户内分配、调整
用量管理无可查看 / 分配成员用量
适合场景个人先上手、熟悉功能团队共同使用

待补充：企业版功能清单、可添加的成员数量、其他企业专属能力

Q9我想先试试，再决定买不买，可以吗？

完全可以，也建议这样做。

先下载个人版客户端用几天，把基本操作摸熟、确认确实能解决你的问题，再考虑是否升级企业版。手感是试出来的，别人讲再多不如自己上手跑一遍。

五、关联与下单

Q10为什么要先关联成为客户？我自己买不行吗？

企业版走的是腾讯云渠道，流程上是先关联、后下单：

  1. 准备一个新的腾讯云账号
  2. 通过我们发给你的邀请链接，关联成为客户
  3. 关联成功后，再下单购买

自己去腾讯云后台是找不到自购入口的（自购需要换用另一个腾讯云账号走，流程更绕）。所以最省事的做法就是先找我们关联。

需要邀请链接的话，直接联系我们（见 Q21）。

待补充：关联操作的具体步骤截图

Q11企业版在哪里购买？

腾讯云官方下单页：

https://cloud.tencent.com/product/workbuddy-enterprise?Is=sdk-topnav

备用入口：https://copilot.tencent.com/pricing/

请先完成 Q10 的关联，再下单，否则下单会受阻。
请使用你已完成实名认证的那个账号登录后再购买，避免账号不一致导致权益归属到其他账户。
购买时填写的超级管理员手机号很重要，它是后续登录管理后台、给成员发货的依据，请谨慎填写。
Q12一个腾讯云账号能买几个 WorkBuddy 账号？

可以买多个。按需购买，买完再分配给团队成员即可（1 人起购）。

待补充：单个腾讯云账号可购买的数量上限

Q13买完之后怎么分配给同事？

在管理后台的成员管理里点「添加成员」，填写成员信息即可（会跳转到腾讯统一身份平台）。

添加后成员账号是未激活状态，需要同事本人完成激活，步骤见 Q17。

详细配置指引：https://www.codebuddy.cn/docs/ide/Codebuddy-enterprise-edition/Codebuddy-enterprise-purchase

待补充：成员添加界面的截图

Q14购买完成后，第一步做什么？

作为企业的第一个账号：先创建企业账号，然后邀请其他成员进入。

顺序别反，先把企业账号建起来，后续成员邀请、席位分配才顺。

企业账号建好后，登录管理后台操作，后台地址见 Q16。
Q15价格是多少？能开发票吗？

目前企业版价格为 198 元 / 账号 / 月，发票可以在腾讯云后台自行开具。

六、后台与团队管理

Q16已经成为会员了，管理后台在哪里？高频

登录地址（复制粘贴到浏览器打开）：

https://www.codebuddy.cn/login/?platform=admin&state=0&redirect_uri=https%3A%2F%2Fcopilot.tencent.com%2Fadmin%2Foverview

用购买时填写的超级管理员手机号登录，登录成功后会直接进入管理后台（copilot.tencent.com/admin/overview）。

支付成功后，后台需要 3–5 分钟配置产品资源，如果刚进去没看到内容，等几分钟再刷新。
如果一个人关联了多个企业版后台，登录时要选择刚刚支付成功的那个账号。
建议把这个地址收藏到浏览器书签，下次直接从书签进，不用再翻聊天记录。

在后台里可以做这些事：添加 / 管理成员、查看和调整用量、扩容许可证、续费。

Q17添加成员之后，同事怎么激活？

添加成员后，该账号处于未激活状态，需要同事本人完成一次激活：

  1. 同事会收到一条短信通知
  2. 点击短信里的链接完成验证
  3. 页面提示「加入成功」，即为激活完成，可以正常使用了
如果同事说没收到短信，先去后台确认成员手机号是否填对。
Q18成员的使用额度是怎么算的？用完了怎么办？

每个企业成员默认有 2000 积分的配额，用完会无法继续使用，需要管理员调整。

  • 调整额度：后台 → 用量管理 → 成员用量 → 批量调整 / 单成员调整
  • 查看用量：后台 → 用量管理 → 成员用量（可看团队月固定用量、剩余用量、使用明细）
  • 整个企业积分用完：可购买「加量包」，路径 后台 → 用量管理 → 成员用量 → 加量包
  • 增加席位 / 续费：后台 → 用量管理 → 成员用量 → 许可证

待补充：积分的具体消耗规则（一次对话消耗多少）

七、常见困惑

Q19后台显示的还是 CodeBuddy，是不是买错了？

没有买错，不冲突。

同一个账号在 WorkBuddy 和 CodeBuddy 里都能使用，后台界面上出现 CodeBuddy 的字样是正常的，不影响你使用企业版的功能。

Q20企业知识库、ima、乐享知识库，这几个有什么区别？
  • 企业知识库：就是管理后台里的知识库，团队共用
  • ima：个人知识库，自己用
