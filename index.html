二、注册与认证

Q3从官网自己注册，还是从我们这里注册？

看你的使用场景：

  • 只是个人使用：官网自己注册就行，怎么方便怎么来。
  • 要用企业版协同功能：需要在我们这里注册关联，才能开通多人协作、席位管理这些能力。
Q4我已经注册过一个账号了，还需要重新注册吗？

不需要。直接沿用已注册的账号即可。

重复注册容易把数据分散在多个账号里，后续合并很麻烦，建议一开始就固定一个账号用下去。
另外：如果想使用多账号协同，可以在我们这里注册关联，不用另起新账号。
Q5注册完成后第一步要做什么？

先完成账号实名认证。

未实名认证的账号在后续购买、企业协作等环节会受限，建议注册后第一时间完成。

建议直接认证企业账户，后续办理账号关联、开具发票等都会方便很多。

三、账号与登录

Q6一个账号可以几个人同时登录吗？

个人版不支持多人共用。

个人版账号与一个微信或手机号绑定，登录身份是唯一的，无法用于企业协作。如果确实需要多人使用，请看 Q7。

Q7我想让团队一起用，怎么办？

升级企业版。企业版可以在企业账户内统一管理成员，并按需分配席位；人员变动时，席位可以在账户内重新分配，不需要重新购买。

买完之后怎么把席位分给同事，见 Q13。

四、个人版 / 企业版怎么选

Q8个人版和企业版主要区别是什么？

核心区别在协作能力：

个人版企业版
登录方式一个微信 / 手机号企业账户统一管理
多人协作不支持支持
席位管理无可在账户内分配、调整
用量管理无可查看 / 分配成员用量
适合场景个人先上手、熟悉功能团队共同使用

Q17添加成员之后，同事怎么激活？

添加成员后，该账号处于未激活状态，需要同事本人完成一次激活：

  1. 同事会收到一条短信通知
  2. 点击短信里的链接完成验证
  3. 页面提示「加入成功」，即为激活完成，可以正常使用了
如果同事说没收到短信，先去后台确认成员手机号是否填对。
Q18成员的使用额度是怎么算的？用完了怎么办？

每个企业成员默认有 2000 积分的配额，用完会无法继续使用，需要管理员调整。

  • 调整额度：后台 → 用量管理 → 成员用量 → 批量调整 / 单成员调整
  • 查看用量：后台 → 用量管理 → 成员用量（可看团队月固定用量、剩余用量、使用明细）
  • 整个企业积分用完：可购买「加量包」，路径 后台 → 用量管理 → 成员用量 → 加量包
  • 增加席位 / 续费：后台 → 用量管理 → 成员用量 → 许可证

待补充：积分的具体消耗规则（一次对话消耗多少）

九、手机与移动端

Q22手机上能用 WorkBuddy 吗？必须开着电脑吗？

能。手机端有 iOS / Android / 鸿蒙 App 和 微信小程序 两个入口，支持两种模式：

模式需要电脑吗适合什么
云上模式不需要查资料、写文案、处理你上传的照片和文件
本机模式需要，电脑保持运行读写电脑里的文件、执行本地任务
电脑关着也能用云上模式；但要用到电脑里的资料，就得开本机模式，并保证电脑上的 WorkBuddy 正在运行。
Q23手机上能访问手机里的资料吗？能像电脑一样操作文件吗？

不能像电脑那样自由浏览手机文件夹。只能把文件主动交给它，它不能自己去翻。

点输入框旁边的「+」，有四个入口：

入口能做什么限制
拍照实时拍摄纸质文件、发票、白板每次 1 张
照片 / 视频从相册选择一次最多 5 张
手机文件选择 Excel、Word、PDF、TXT 等需手动逐个选择
微信文件从聊天记录里选文件同上

所以这些做不到：

  • 让它「把相册里所有截图整理一下」——它没法遍历相册
  • 批量重命名、批量移动手机里的文件
  • 读取通讯录、短信或其他 App 的数据
处理手机里零散几张照片、几个文件完全够用；要批量整理一堆文件，建议先把文件传到电脑上处理。

十、企业微信集成

Q24企业微信和 WorkBuddy 打通到什么程度？能做什么？

分两个层次：

层次怎么用能做什么
基础：企微助理在企微里给机器人发指令远程操控电脑上的 WorkBuddy：群里 @ 它派活、跟进进度、确认操作、接收任务通知
深度集成用企微账号登录 WorkBuddy在授权范围内读写企微里的消息、文档、表格、会议、邮件、日程、待办、微盘、通讯录

深度集成后可以做的事：

  • 把群聊记录合并转发给它，自动读取里面引用的文档、微盘文件、日程、会议纪要，整理成需求文档或项目看板
  • 一句话总结当天未读消息和未读邮件，按「需处理 / 值得关注 / 其他」分类，单独标出 @ 你的
  • 会后读取会议纪要，提炼结论、分派待办
  • 定时生成日报，自动推送到你的企微或团队群
  • 代你发消息到内部单聊或群聊（发送前需要你本人确认）
涉及员工会议内容、邮件读取的操作，需要员工本人授权；你看不到的文档、进不去的群，它同样访问不了。
Q25想用企业微信集成，需要满足什么条件？

三件事同时满足：

  1. 企业微信已认证：个人注册、未认证的企业暂时用不了
  2. 版本到位：WorkBuddy 5.8.0 及以上，企业微信 5.0.12 及以上
  3. 走 WorkBuddy 企业版：个人版用不了这套企微能力

入口：企业微信侧边栏会出现「WorkBuddy」图标，管理员可以在那里领取使用、分配账号。

官方提供限免体验名额，可以先试用再决定是否采购。试用有期限和额度，到期后需要正式开通才能继续使用。
企微认证不等于 WorkBuddy 企业版——这是两套独立的订阅，需要分别满足。
Q26用企业微信登录，是企业账号还是个人账号？积分怎么算？

登录后是企业版身份，绑定你所在的企业微信组织架构，不是个人账号。

个人版企业版（企微登录）
账号归属个人企业
积分管理自己购买、自己使用企业统一采购和分配
用量查看个人中心管理后台按成员、部门查看
个人版和企业版是两套独立的积分账本，不互通、不合并。
如果企业还没购买企业版，可以先用官方限免体验名额；试用到期后，个人版账号不会自动转成企业版，也不能继续使用企微集成能力。

十一、Outlook 邮件接入

Q27Outlook 邮箱能接到 WorkBuddy 吗？个人邮箱行吗？

能，通过自定义 MCP 连接器接入。个人 Outlook 邮箱就可以，不需要 Microsoft 365 订阅。

账号类型能不能接需要什么
个人 Outlook / Hotmail可以自己完成授权即可
企业 / 学校 Microsoft 365可以通常需要企业 IT 配合授权

接入前需要在微软 Azure 注册一个应用，拿到应用 ID，再在 WorkBuddy 里配置连接器。个人账号第一次注册时会自动创建一个免费目录，不产生费用。

配置完成后需要重启 WorkBuddy，并在连接器页面点「信任」才会生效。
Q28企业版 Outlook 接入，需要管理员权限吗？

不一定，取决于企业 Microsoft 365 的租户设置：

租户设置谁来授权
允许用户自行同意第三方应用员工本人授权即可
已关闭用户同意必须由 IT 管理员做管理员同意

多数企业出于合规考虑会关闭用户同意，所以实际推进时通常需要 IT 部门配合。推荐做法是由企业 IT 在自己的租户里注册应用，提供应用 ID 和租户 ID。

另外，会议室查询这类权限必须管理员同意，无法由个人授权。

接入使用的是「委托权限」：只能操作当前登录人本来就有权访问的邮件和日历，拿不到其他人的邮箱。
Q29Outlook 接上之后能做什么？能帮我给客户回邮件吗？

可以。主要能力：

类别能做什么
读邮件按发件人、主题、日期、关键词搜索，读全文和整条对话
写邮件起草、回复、全部回复、转发、发送
处理邮件批量标记、移动、分类、导出、下载附件
日历查看、创建、修改、取消日程

「帮客户回邮件」的流程是：找到邮件 → 读完整对话 → 生成回复草稿 → 你确认 → 发出。不会绕过你直接发。

需要注意两点：

  • 不能收到邮件就自动回。它需要你发起任务，或者配定时任务定期检查；不是常驻监听的邮箱助手。
  • 共享邮箱只能读，不能从共享邮箱发信或回复。如果要用 support@ 这类共享邮箱统一回信，需要另行确认方案。
建议先开启只读模式、设置收件人白名单和发信上限，确认稳定后再开放发送权限。

十二、专家与技能

Q30专家和专家团是什么？它们自带知识吗？知识会更新吗？

专家是「角色切换」机制：用「人设 + 方法论 + 工具链」，让 WorkBuddy 以某个领域的专家身份来完成任务。专家团则是「协作执行」机制：由团长拆解任务、分派给多位专家并行执行，最后整合交付。

专家本身不是知识库。官方说明：专家不主动获取系统权限，只处理你主动提供的对话和上传文件；只有配备了 Skill 或 MCP，才会在你授权下间接访问外部服务。

它的「知识」实际来自三层：

来源会不会更新说明
底层大模型随模型版本训练数据有截止日期，不联网就不知道之后的信息
你提供的材料每次对话上传的文件、粘贴的内容、对话上下文
挂载的 Skill / MCP / 知识库取决于外部系统联网检索、乐享 / ima 知识库、企业系统

所以「专家知识更新」要分两件事看：专家包本身有版本迭代（方法论、提示词会更新），但这不是知识库；真正决定它知不知道最新信息的，是模型版本、有没有联网、以及你给了什么资料。

专家团会调用多位专家协同，积分消耗通常是单个专家的数倍，使用前请确认积分充足。
想让专家掌握企业自己的知识，可以接入乐享 / ima / 腾讯文档知识库，或者用「我的专家」把企业的 SOP、话术沉淀进去。
Q31Skill、专家、专家团有什么区别？该怎么选？
类型本质什么时候用
Skill工具能力：让 AI 能做某件事需要 AI 具备某种能力，比如生成 PPT、处理 Excel、联网检索
专家能力 + 经验：懂某个领域的 AI 角色有一个明确的单点问题，需要专业视角和方法
专家团多位专家 + 协作流程任务复杂，需要多个角色配合完成
简单记：Skill 是「能力」，专家是「能力 + 经验」，专家团是「多位专家 + 协作流程」。

十三、AI 准确性与可靠性

Q32AI 会编数据吗？WorkBuddy 的幻觉问题怎么避免？

会。WorkBuddy 底层调用的是大语言模型，只要使用大模型，就可能出现「幻觉」——生成看起来合理、但并不真实的内容。这一点目前无法彻底消除，但可以识别和规避。

办公场景里的幻觉主要分两类：

类型表现怎么发现
事实幻觉编造不存在的数据、来源、人名或案例要求标注出处，逐个核对
执行幻觉说「已完成」「已读取」，但实际没有做看产物文件是否存在、执行过程是否留痕

WorkBuddy 在执行层面做了几件事，让「执行幻觉」相对容易发现：

  • 文件是真实读写的，产物会落到本地，能不能打开一验就知道
  • 执行过程可见，读了哪些文件、执行了什么命令都有记录
  • 删除、修改等敏感操作需要确认，降低误操作风险

但要注意：能执行不等于算得对。统计口径、去重规则、占比计算这类工作，仍然需要人工复核。

降低幻觉的五个习惯：
① 要求标注数据来源和文件页码；
② 不接受口头「已完成」，要求给出文件路径；
③ 统计口径先说清楚，别让它自己猜；
④ 金额、占比、人数等关键数字二次核对；
⑤ 长文档拆章节处理。
涉及对外发布、财务决策、合同条款的内容，建议保留人工审核环节，不要直接采用 AI 输出。

十四、系统对接与数据安全

Q33ERP 等外部系统能直接对接吗？要不要额外付费？

能对接，前提是对方系统有可用的数据出口。常见有三种方式：

方式说明费用
标准 API系统自带开放接口，有文档和访问凭证一般不需要额外购买
数据库只读账号直接连数据库读取，需要 IT 开权限不产生接口费
厂商定制开发老系统没有标准接口，需要厂商单独开发通常需要开发费

WorkBuddy 通过 MCP（连接器协议）接入，配置本身不额外收费，正常消耗积分。

评估前先向对方 IT 确认三件事：有没有 API 文档、支不支持 Token 或 OAuth、有没有测试环境。这三项不具备，通常意味着要先做接口开发。
数据结构复杂时，建议先明确要取哪些字段、用什么口径，避免接完才发现数据对不上。
Q34把接口权限给 AI，会不会有改数据的风险？

风险是真实存在的。关键不在 AI，而在用哪个账号接入。

做法说明
用只读账号不要用总账、财务总监这类高权限账号
限制范围数据库层限制 IP，只开放必要的表和视图
留审计日志能追溯谁在什么时候取了什么数据
用默认权限WorkBuddy 权限档位选「默认权限」，减少敏感操作自动执行
涉及财务、人事等敏感系统时，建议由 IT 单独开一个接口账号，明确使用范围和有效期，不要共用个人账号。
Q35社保这类系统登录，要把账号密码交给它吗？

不需要。这类网页系统通常通过扫码登录，不需要把账号密码交给 AI。

但仍要注意，扫码本身也是一次授权，建议：

  • 使用专用账号，不要用个人主账号
  • 用完及时退出，不长期保持登录状态
  • 不要把密码直接粘贴到对话里
不同网站支持的登录方式不一样，实际以该系统的登录页面为准。
Q36个人版怎么保证数据安全？除了脱敏还要做什么？

脱敏只解决一个环节，数据安全要分三层看：

手段防的是什么
使用本地工作空间让数据留在你自己的电脑上，不离开本地环境
数据脱敏避免敏感信息进入模型上下文
企业版 / 专享版 / 私有化满足企业级的隔离、审计和合规要求

官方对数据的说明是：数据在本地环境执行处理，服务端仅处理数据片段，用后即弃、不保存、不用于模型训练。

如果只是个人试用，至少做到两条：选本地工作空间 + 处理前脱敏。
如果涉及公司敏感数据，建议通过公司统一渠道申请企业版，不要用个人版处理。
Q37企业版管理员能看到同事的文件吗？同事之间能互相看到吗？
对象能不能看到
同事之间不能，各自只能看到自己的对话和文件
公共空间可以，放进公共空间的成果是团队共享的
管理员可见范围取决于企业后台的配置和权限设置

如果企业对可见性有明确要求，建议在管理办法里写清楚：谁能查、什么情况下查、查到什么程度。

具体的管理员权限以实际后台版本和企业的权限配置为准。

现象处理方式
