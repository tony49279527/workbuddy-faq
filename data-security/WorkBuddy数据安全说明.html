一、先回答最敏感的那个问题：会被拿去训练吗？

结论：不会。而且这不是"设置出来的"，是产品固有机制 + 协议承诺。

官方对这件事有三句可以直接引用的原话：

"数据本地执行不上传：所有数据在用户本地环境执行处理，从根本上杜绝数据泄露风险。"
"服务端仅处理数据片段：用后即弃，不保存，不用于模型训练。" —— WorkBuddy 官方文档《常见问题 → 数据安全说明》
codebuddy.cn/docs/workbuddy/…/FAQ
"团队数据永不用于模型训练，全程加密、可审计、可导出。" —— 腾讯云 WorkBuddy 产品页 FAQ
cloud.tencent.com/act/pro/workbuddy
"用户输入数据仅用于实时推理，推理完成后当场丢弃，不存储也不用于模型训练。" —— 腾讯官方 WorkBuddy 数据安全说明

还有一条法律层面的：

"腾讯云不会存储您的代码，也不会将其用于其他未经您授权的场景，例如模型训练。" ——《腾讯云 WorkBuddy 软件许可及服务协议》/ 隐私保护指引

那在哪里设置？ —— 不需要设置，这不是一个开关。它是"本地执行 + 服务端只做片段推理"这套架构带来的必然结果。企业后台 38 个页面里没有任何"训练开关"，因为根本不存在这个风险点。

⚠ 一个关键区分：这其实是两个不同的问题

问题准确回答
"我的数据会被拿去训练模型吗？" 不会。文件在本地处理，上云的只是"完成任务所必需的一小段内容"，推理完即丢弃，不保存、不入训练集。（官方已明示）
"那腾讯能'看到'我的文件吗？" 这是"访问与管控"问题，不是"训练"问题。WorkBuddy 只能读你显式授权的文件夹，系统敏感目录自动拦截，高危操作要二次确认；企业版还能由管理员把授权范围、日志留痕、外发范围全部锁死。

二、数据是怎么流动的

核心一句话：文件本体不出电脑，上云的只是"必要片段"，用完即弃。

本地模式（默认）
  • 文件读写、分析、生成都在本机完成
  • Excel / PDF / 合同等原始文件不离开硬盘
  • 云端只负责"转发指令 + 返回结果"
云端模式（远程/自动化时）
  • 计算在腾讯云的隔离沙箱里跑
  • 沙箱之间彼此不可见，任务完成即清除
  • 云端访问不到你电脑上的任何路径

来源：腾讯云开发者社区官方文章

三、四层隔离体系

官方把安全体系概括为「三层纵深防御」（技术防御 / 管理管控 / 合规审计）。落到"隔离"这件事上，可以拆成四个层次：

层级隔离什么机制（官方口径）
① 本地数据隔离 AI 与你的操作系统、与你没授权的目录 安全沙箱（OS API 层中转判断）、文件系统隔离（只能访问授权工作空间）、防沙箱逃逸、默认只读 + 显式批准、allow/ask/deny 三态规则
② 网络隔离 数据出入本机的通道 HTTPS 全链路加密（TLS 1.2/1.3）、复用 IM 内置 WebSocket 通道（不需要在防火墙开额外端口）、安全通信网关 + Gateway Token 鉴权（不依赖 frp/ngrok/Tailscale 等第三方穿透）
③ 租户 / 物理隔离 你的数据和其他企业、和公网 SaaS 多租户逻辑隔离 → VPC 专享版：后台服务、数据库、向量库全部部署在独立 VPC，与其他租户物理隔离，服务间通信走私网，企业可用私有链接从办公内网直连 → 私有化：数据与计算全在企业本地机房
④ 管控 / 审计隔离 "谁、在什么时候、能对什么做什么" SSO 单点登录 + 组织架构同步、Credit 额度控制（按部门/角色）、IP 白名单、精细化工具调用权限、Skill 安全审计 + skill-scanner 本地扫描、操作与对话日志留痕

关于"物理隔离"的准确表述

只有 VPC 专享版 / 私有化部署才是"物理级隔离"。官方原文：

"物理级隔离：后台服务、数据库、向量数据库等所有组件部署在独立 VPC 内，与其他租户实现物理隔离，从根本上杜绝数据泄露或被其他租户访问的风险。"
"数据主权与零泄露：企业拥有 VPC 环境的绝对网络控制权和数据主权。" —— WorkBuddy 官方文档《数据安全说明 · VPC 专享版安全架构》

SaaS 标准版为「逻辑隔离 + 企业级安全管控」；物理级隔离仅适用于 VPC 专享版与私有化部署两档。

四、客户端「安全中心」：每个员工本机上的锁

这是 2026 年 8 月上线（v5.0+）的能力，默认开启，入口在客户端左下角头像 → 设置 → 安全中心。这一块回答的是"装到员工电脑上，我怎么放心"。

分组能力说明
沙箱安全 沙箱安全（总开关） AI 执行的指令先经沙箱判断，不直接与操作系统交互；工作空间内正常读写放行，格式化磁盘、遍历系统根目录等越权操作被拦截
文件安全（三态规则） 按文件路径配置 读取 / 写入 / 删除，可分别设为 允许 / 询问 / 拒绝，并支持白名单与黑名单
命令安全 / 网络安全 命令：按前缀配置询问或放行名单；网络：按域名/URL 配置规则，远程 HTTP 默认询问、本地 HTTP 默认放行
数据安全 安全网关 / 传输加密 工作空间出入流量统一过安全网关；本地与云端通信端到端加密（默认开启）
敏感保护 默认开启，检测并拦截票据、密码等敏感信息意外泄露，支持自定义检测规则
删除保护 开启后删除的文件优先进废纸篓 / 回收站（OS API 层硬拦截，不靠文字识别），误删可找回
批量删除审批 一次删除达到设定数量（默认 50）时需审批（需先开启删除保护）
自动备份 修改已有文件前自动生成快照，不限文件类型（PPT / Word / 图片 / PDF 均可还原）；备份总上限默认 3000 MB
其他 内置运行时 给 AI 一个独立工作环境（内置 Node.js / Python / Git Bash），减少对员工电脑本地开发环境的影响
工具管控（Tool / MCP） 逐个启用或禁用 Agent 可调用的工具和 MCP 服务；可整体关闭自建 MCP；配置保存在本地、当前客户端所有 Agent 生效
审计中心 / 系统授权 审计中心查看记录；macOS 下可管理完全磁盘访问、辅助功能、自动化等系统授权

员工本机可以自查的"4 + 3"

4 个建议保持开启的默认开关：安全沙箱 · 自动备份 · 删除保护 · 内置运行时

3 个可以自己加的"审批名单"：

  • 文件：把 财务资料 / 合同 / 个人证件 / 私人照片，以及 .ssh、.env 等密钥目录 加进强制审批黑名单
  • 命令：把 git push、npm publish、生产部署脚本 加进需人工确认名单
  • 网络：限定可访问的域名 / URL 范围

来源：腾讯官方公众号 / 腾讯搜一搜官方内容 + 官方文档《默认权限与安全沙箱》

五、企业版后台：管理员能做的隔离管控

本节依据 2026-10-09 对企业版管理后台（www.codebuddy.cn/admin）的逐页核对，共 12 个分区、约 38 个页面。

后台位置能做什么（对数据安全的意义）
安全中心 → 客户端安全 全后台唯一能落到成员本机行为的强管控。新建策略 = 基本信息 + 4 个分页（沙箱安全 / 数据安全 / 内置运行时 / 敏感数据保护）+ 生效范围（部门 / 成员）+ 优先级。
· 最硬一道锁 = 关闭「允许对话内开启完全访问」，成员无法绕过确认直接执行敏感操作
· 机制：企业策略是底线成员不可突破；多条策略命中只生效优先级最高那条；重启客户端立即生效（否则约 10 分钟同步）
注意：客户端安全策略目前仅 WorkBuddy 支持，CodeBuddy(IDE) 与企业智能体暂不支持
企业设置 → 网络设置（IP 白名单） 限定可登录的 IP 段；只填 127.0.0.1 等于禁止全部外部 IP，杜绝非办公网络接入
客户端配置 → 分享与协作 控制内容的发布范围 / 协作范围。财务场景必须锁「仅组织内」——一旦开启"全网可见"，成员就能把链接发到公网
日志管理 操作日志（含操作人 IP）；对话日志为全量留痕。⚠ 对话日志开启前页面会要求先获得授权并告知成员；关闭会清空已有记录
AI 资源管理 → 模型管理 配置可用模型清单与可见范围；可禁止调用海外模型，规避数据出境风险
成员与部门 / 管理员角色 / 成员授权 成员与部门来自腾讯统一身份 OneID（后台只读，加人须回 OneID）；角色权限精细到"谁能用什么"；对成员的客户端可「授权 / 取消授权」
技能 / 专家 / Connector / 知识库 均有「下发策略 + 可见范围」；Skill 有安全审计与风险分级；skill-scanner 安装前本地安检
安全中心 → 综合管理 技能安装安全：可禁止安装高风险技能

给财务部落地时的"优先级清单"

  1. 先关掉「允许对话内开启完全访问」（客户端安全策略里）—— 性价比最高的一道锁
  2. 把 财务资料 / 合同 / .ssh / .env 目录 配成"强制审批 / 拒绝"路径规则
  3. 「分享与协作」锁死在「仅组织内」
  4. 「网络设置」配 IP 白名单，只放行办公网出口
  5. 「模型管理」禁用海外模型
  6. 「日志管理」开启操作日志（对话日志视合规要求，开启前务必告知+授权）
  7. 给"财务部"单独建一条客户端安全策略，优先级设为最高

六、三档部署模式与合规认证

部署模式隔离级别适合谁
SaaS 公有云
（SaaS 企业版）		 多租户，共享公共云 + IAM 身份逻辑隔离 中小团队快速启动；数据在腾讯云，享企业级安全防护
VPC 专享
（专有云企业版）		 独立 VPC，物理级隔离，私网访问，数据主权归企业 中大型企业、合规要求较高（金融/政企）
私有化部署 全栈部署在企业本地机房，完全阻断外网 金融、政务、信创环境，最高安全等级

合规认证

WorkBuddy 作为腾讯云产品，继承腾讯云安全合规体系，官方 FAQ 列出的包括：

  • ISO 27001 信息安全管理体系（UKAS 国际认证 + CNAS 国内认证）
  • ISO 27018 个人信息保护国际认证
  • ISO 27701 隐私安全管理体系
  • CSA STAR 云安全管理体系认证（金牌）
  • 网络安全等级保护 三级 / 四级
  • PCI-DSS 支付卡行业数据安全标准认证
  • SOC 审计报告
  • 可信云数据安全认证

—— 来源：腾讯云官方文档《WorkBuddy 常见问题 · 合规资质保障》

官网首页另有一句：已通过 ISO 27001 / SOC 2 / 等保三级；传输与存储全程 TLS / AES-256 加密，密钥独立托管。
